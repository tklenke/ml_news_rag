## Answer

You’re probably referring to **EFII (Electronic Fuel Injection and Ignition)**, a modern electronic system used on Lycoming-powered Cozy projects. Unlike conventional Bendix- or Airflow Performance-style mechanical injection, EFII needs excess fuel returned to the tank the fuel came from. Builders commonly use a **duplex fuel selector valve** to route both the supply and return correctly.

**SDS EFI** is another electronic system discussed by Cozy builders, but return-line requirements depend on the system’s configuration. Not all fuel-injection systems need a return to the tanks.

One terminology note: the fuel supply is pressurized; the return line carries bypass fuel back to the selected tank and is not generally a high-pressure line in the same sense. Follow the engine/system manufacturer’s installation guidance for the required routing and line sizing.
