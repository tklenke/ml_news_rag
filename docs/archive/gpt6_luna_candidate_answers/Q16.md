## Answer

For a Cozy, the commonly cited nominal canard incidence is about **3° relative to the longerons**. But don’t set it from that number alone: use the **corrected Template F from Cozy Newsletter 80** (and matching Template G), since the template defines the intended geometry and reference.

For a new build, aim toward the **high side of the template’s positioning range**. In flight, a useful check is that the elevators are near trail or slightly reflexed at mid-CG cruise. Canard incidence is only one part of the pitch setup; wing incidence, CG, and canard contour also matter.
